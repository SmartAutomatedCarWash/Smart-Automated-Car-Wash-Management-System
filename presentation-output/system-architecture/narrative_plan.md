# AutoWash System Architecture

## Audience
Project reviewers, lecturers, developers, and technical stakeholders.

## Objective
Present a repository-aligned, professional system architecture that explains both the logical component boundaries and the runtime communication paths.

## Narrative arc
1. Establish the role-based web platform, modular Spring Boot backend, persistence, and external integrations.
2. Explain how synchronous requests, callbacks, database operations, and realtime events travel through the system.

## Slide list
1. Logical System Architecture
2. Runtime Communication and Event Flow

## Source plan
Use the implementation and configuration available on `origin/dev` at commit `b5ad575`.

## Visual system
16:9 technical diagram; white canvas; dark navy typography; cyan for presentation, purple for application services, green for persistence, and orange for integrations. Solid arrows represent requests or commands; dashed arrows represent responses, callbacks, or events.

## Asset and editability plan
No decorative raster assets are required. All architecture components, labels, boundaries, arrows, and legends remain editable PowerPoint objects.
